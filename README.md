# Customer Order Management System

## Project Overview

The Customer Order Management System is a Python-based application developed to manage customer records and customer orders efficiently. The application provides a simple Tkinter graphical user interface (GUI) through which users can add, view, search and update customer and order information.

It also performs order analysis and generates visual reports to help understand order status, sales and customer activity.

## Objectives

- Manage customer records.
- Manage customer orders.
- Update order status.
- Search and filter customer and order records.
- Calculate order values and sales summaries.
- Analyze customer and order activity.
- Generate meaningful visual reports.
- Store data permanently using CSV files.
- Provide input validation and exception handling through a user-friendly GUI.

## Technologies Used

- Python
- Tkinter
- Pandas

- CSV File Handling

## Project Modules

### `main.py`
Provides the main Tkinter graphical user interface and connects the different modules.

### `customers_manager.py`
Handles customer-related operations such as adding, viewing, searching and updating customer records.

### `orders_manager.py`
Handles order-related operations such as adding orders, updating order status and managing order information.

### `analysis.py`
Performs order and sales analysis using Pandas and NumPy and generates Matplotlib visualizations.

### `validators.py`
Provides input validation functions for customer and order data.

## Data Storage

The project uses CSV files for persistent storage:

- `customers.csv` - stores customer records.
- `orders.csv` - stores order records.
